# การค้นหาฟอร์ม Price Comparison (PRO-CPC)

หน้าค้นหาฟอร์มเปรียบเทียบราคา (Price Comparison Form no.) ใช้สำหรับค้นหาและดูรายการฟอร์มทั้งหมดที่เคยสร้างไว้ โดยสามารถกรองเงื่อนไขการค้นหาได้หลายเงื่อนไขพร้อมกัน

## เงื่อนไขการค้นหา

<FancyLightboxImage src="/image/purform/pur-cpc/search/before-search.png"/>

กรอกเงื่อนไขที่ต้องการค้นหา (ไม่จำเป็นต้องกรอกทุกช่อง ระบบจะค้นหาเฉพาะช่องที่กรอก/เลือกไว้เท่านั้น)

1. **Requester** — รหัสพนักงานของผู้ขอ (Requester) เช่น 22013
2. **Planner** — รหัส Planner เช่น G
3. **Status** — สถานะของฟอร์ม เลือกได้จาก dropdown
   - **Draft** — ฟอร์มที่บันทึกร่างไว้ ยังไม่ได้ส่ง
   - **Created** — ฟอร์มที่สร้างแล้ว
   - **Used** — ฟอร์มที่ถูกนำไปใช้งานแล้ว
4. **Vendor code** — รหัส Vendor เช่น 10003
5. กดปุ่ม **Search** เพื่อค้นหา

::: tip
ถ้าไม่กรอกเงื่อนไขใดเลยแล้วกด Search ระบบจะแสดงฟอร์มทั้งหมด
:::

## ผลลัพธ์การค้นหา

<FancyLightboxImage src="/image/purform/pur-cpc/search/after-search.png"/>

หลังกด Search ระบบจะแสดงผลลัพธ์เป็นตาราง ประกอบด้วยข้อมูล

- **No.** — ลำดับที่
- **Price Comparison no.** — เลขที่ฟอร์ม (เช่น PRO-CPC26-000001) กดที่เลขเพื่อเปิดดูรายละเอียดฟอร์มได้
- **Input by** — ผู้กรอกฟอร์ม
- **Request by** — ผู้ขอ
- **Function** — สูตรการคำนวณเปรียบเทียบราคา
- **PLANNER** — รหัส Planner
- **MODE** — โหมดการเปรียบเทียบ (E / A)
- **VENDER CODE** — รหัส Vendor
- **Amount of Present price (KB/Y)** — ยอดเงินราคาปัจจุบัน
- **Amount of New price (KB/Y)** — ยอดเงินราคาใหม่
- **Amount of Difference (KB/Y)** — ยอดเงินส่วนต่าง
- **Ratio (%)** — อัตราส่วนเปอร์เซ็นต์
- **Request Date** — วันที่ขอ
- **Status** — สถานะฟอร์ม (ป้ายสีส้ม = Draft, ป้ายสีเขียว = Used)

::: warning
หากไม่พบข้อมูลตามเงื่อนไขที่ค้นหา ตารางจะแสดงข้อความ "ไม่มีข้อมูลในตาราง"
:::
