# ภาพรวมระบบ Form (New Webflow)

**New Webflow (Form System)** คือระบบแบบฟอร์มอิเล็กทรอนิกส์และสายการอนุมัติ (E-Form & Approval Workflow) สำหรับจัดการคำร้อง การตรวจสอบ และการอนุมัติเอกสารภายในองค์กรแบบไร้กระดาษ (Paperless) พร้อมติดตามสถานะได้ทุกขั้นตอน

---

## วัตถุประสงค์ของระบบ

- **ลดขั้นตอนและกระดาษ**: เปลี่ยนแบบฟอร์มเอกสารกระดาษเป็นแบบฟอร์มดิจิทัลที่กรอก แนบไฟล์ และค้นหาย้อนหลังได้สะดวก
- **สายการอนุมัติมาตรฐาน**: กำหนดลำดับผู้อนุมัติอัตโนมัติตามโครงสร้างองค์กรและเงื่อนไขของแต่ละแบบฟอร์ม
- **โปร่งใส ตรวจสอบได้**: เก็บประวัติการสร้าง การแก้ไข การอนุมัติ และการส่งกลับแก้ไขครบทุกขั้นตอน (Audit Trail)
- **เชื่อมต่อข้อมูลองค์กร**: เชื่อมต่อระบบยืนยันตัวตนกลาง (`@amec/webasset`) อีเมลแจ้งเตือน และระบบรายงาน/ส่งออกไฟล์ Excel & PDF

---

## โมดูลและประเภทแบบฟอร์มหลักในระบบ

ระบบ Form รองรับแบบฟอร์มแยกตามสายงานและหน่วยงานหลัก ดังนี้:

| หมวดหมู่ | ตัวย่อ | ตัวอย่างการใช้งานหลัก |
| :--- | :--- | :--- |
| **IS Form** | `IS-*` | คำร้องด้านระบบสารสนเทศ เช่น Confirm Sheet (`IS-CFS`), Result Confirmation (`IS-JDR`), Special Authorization ID (`IS-SPC`), Temporary User (`IS-TID`), Varied Off AS400 (`IS-OFF`), ระบบพัฒนาโปรแกรม (`IS-DEV`) |
| **QA Form** | `QA-*` | แบบฟอร์มด้านประกันคุณภาพ เช่น E-Self Inspection and Authorize (`QA-INS`) |
| **GA & HR Form** | `GP-*` / `ST-*` | คำร้องด้านบุคคล สวัสดิการ การลา โอที การเดินทาง และความปลอดภัย |
| **PS / MFG / IE / FE Form** | `PS-*`, `MFG-*`, `IE-*`, `FE-*` | แบบฟอร์มด้านการผลิต คลังสินค้า วิศวกรรมอุตสาหการ และบำรุงรักษาเครื่องจักร |
| **FIN / PUR / DED / MAR Form** | `FIN-*`, `PUR-*`, `DED-*`, `MAR-*` | แบบฟอร์มด้านการเงิน การจัดซื้อ/อนุมัติใบสั่งซื้อ (PO) วิศวกรรมออกแบบ และการตลาด |
| **Advanced Tools** | `Tool` | เครื่องมือเสริมสำหรับผู้ดูแลและผู้จัดการ เช่น QR Code Generator และรายงานสรุป |

## แผนผังการอนุมัติแบบ End-to-End

```text
┌───────────────────┐     ┌───────────────────┐     ┌───────────────────┐     ┌───────────────────┐
│  1. Requester     │     │  2. Approver      │     │  3. Manager       │     │  4. Completed     │
│  สร้าง/ยื่นคำร้อง  │ ──▶ │  ตรวจสอบ/อนุมัติ   │ ──▶ │  อนุมัติขั้นสุดท้าย  │ ──▶ │  เสร็จสิ้น/จัดเก็บ  │
│  (Draft / Submit) │     │  (Wait Approval)  │     │  (Final Approve)  │     │  (Finish / Report)│
└───────────────────┘     └─────────┬─────────┘     └─────────┬─────────┘     └───────────────────┘
         ▲                          │                         │
         │                          ▼                         ▼
         └────────────── ส่งกลับแก้ไข / ไม่อนุมัติ (Return / Reject) ──────────────┘
```

### สถานะหลักของเอกสารในระบบ
1. **Under Preparation (ร่างเอกสาร)**: ผู้ยื่นคำร้องกำลังจัดเตรียมข้อมูล ยังไม่ได้ส่งเข้าสายการอนุมัติ
2. **Wait for Approval (รออนุมัติ)**: เอกสารอยู่ในคิวของผู้อนุมัติลำดับปัจจุบัน พร้อมแจ้งเตือนทางอีเมล
3. **Coming Soon (กำลังจะถึงคิว)**: เอกสารที่กำลังผ่านลำดับก่อนหน้าและจะส่งต่อมายังผู้อนุมัติในลำดับถัดไป
4. **Approved / Rejected (อนุมัติแล้ว / ไม่อนุมัติ)**: รายการที่ดำเนินการพิจารณาเรียบร้อยแล้ว
5. **Representative (ตัวแทนอนุมัติ)**: รายการที่ได้รับมอบหมายให้พิจารณาแทนผู้อนุมัติหลักในช่วงที่ลาหรือไม่อยู่ปฏิบัติงาน
6. **Finish (เสร็จสมบูรณ์)**: เอกสารผ่านครบทุกขั้นตอน สามารถพิมพ์ PDF หรือดูรายงานสรุปได้

## วิธีเริ่มต้นใช้งาน

1. **เข้าสู่ระบบ (Login)**:
   - คลิกปุ่ม **Login** ที่มุมขวาบนของแถบเมนู เพื่อเข้าสู่ระบบผ่านหน้า Authen กลางด้วยรหัสพนักงาน
   - เมื่อเข้าสู่ระบบเรียบร้อยแล้ว กลับมาที่หน้าคู่มือ ระบบจะตรวจสอบสิทธิ์ให้อัตโนมัติเมื่อกลับเข้าแท็บ (`window focus`)
2. **เลือกคู่มือจากเมนูด้านซ้าย (Sidebar)**:
   - เมนูจะกรองแสดงเฉพาะหัวข้อที่ตรงกับ Role ของคุณโดยอัตโนมัติ
3. **สร้างหรือติดตามคำร้องในระบบ Form**:
   - เข้าเมนู **Create** เพื่อเลือกประเภทแบบฟอร์ม กรอกข้อมูล แนบไฟล์ และกดส่งอนุมัติ
   - ติดตามสถานะได้ที่เมนู **Mine** หรือ **Wait for Approval**
4. **ตั้งค่าการใช้งานส่วนตัว**:
   - สามารถตั้งค่า **ตัวแทนอนุมัติ (Representative)** และ **การแจ้งเตือนอีเมล (E-Mail Acknowledge)** ได้จากเมนู Setting ในระบบหลัก

---

## ตารางสิทธิ์การเข้าถึงเอกสารตาม User Role

ระบบคู่มือนี้ตรวจสอบบทบาทจากสิทธิ์การเข้าสู่ระบบจริง (`GROUP_CODE`) และกรองการเข้าถึงเอกสารดังนี้:

| บทบาท (Role) | คำอธิบาย | หน้าแรก / Quick Start / Change Log | คู่มือ IS Form & QA Form | คู่มือ HR / ข้อมูลองค์กร | Advanced Features (QR Code / Admin) |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Admin** (`ADMIN`) | ผู้ดูแลระบบและทีมพัฒนา เข้าถึงเอกสารทั้งหมด | ✅ | ✅ | ✅ | ✅ |
| **Manager** (`MANAGER`) | ผู้จัดการ / ผู้อนุมัติระดับบริหาร | ✅ | ✅ | ✅ | ✅ |
| **Approver** (`APPROVER`) | หัวหน้างาน / ผู้อนุมัติคำร้อง | ✅ | ✅ | ➖ | ➖ |
| **Requester** (`REQUESTER`) | พนักงานผู้ยื่นคำร้องทั่วไป | ✅ | ✅ | ➖ | ➖ |
| **HR** (`HR`) | เจ้าหน้าที่ฝ่ายบุคคลและธุรการ | ✅ | ➖ | ✅ | ➖ |
| **Guest** (`GUEST`) | ผู้เยี่ยมชม (ยังไม่ Login หรือ Session หมดอายุ) | ✅ | 🔒 | 🔒 | 🔒 |

> **หมายเหตุ:** หากคุณยังไม่ได้เข้าสู่ระบบหรือ Session หมดอายุ ระบบจะกำหนดสิทธิ์เป็น **Guest** โดยอัตโนมัติ และสามารถกดปุ่ม **Login** บนแถบเมนูด้านบนเพื่อเข้าสู่ระบบได้ทันที
